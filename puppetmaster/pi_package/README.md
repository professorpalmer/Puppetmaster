# @puppetmaster/pi-pilot

Pi TUI/pilot package. Pi is not a worker adapter.
Do not lease pi as a subprocess. Pi stays the TUI.

## Install

    puppetmaster install-pi-mcp
    pi install PATH_TO_PI_PACKAGE
    pi install PATH_TO_PACKAGE
Writes ~/.pi/agent/mcp.json and settings.json packages.
Prefer start_implement / start_agentic / start_prewalk, then effort_index / show.
Artifacts, not transcripts. Size the runtime, then nuke the job.
